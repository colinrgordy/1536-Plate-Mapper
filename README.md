# 1536-Well Plate Mapper & HTS Calculator

An interactive web application designed for high-throughput screening (HTS) workflows, specifically optimized for **1536-well plate** layouts.

## Key Features
* **Interactive Mapping:** Select and label well blocks using a high-fidelity Plotly interface.
* **HTS Calculator:** Automatically calculates Master Mix volumes based on plate density and assay volume.
* **Multiplex Possible:** Designed for dual-readout assays (e.g., CTF + HiBiT).
* **GLP-Ready Export:** Generates standardized PDF layouts for lab notebooks and record-keeping.

## Technical Stack
* **Language:** Python 3.9
* **Framework:** Shiny for Python
* **Visualization:** Plotly.py
* **Deployment:** shinyapps.io

## Background
Developed for use in translational science research to streamline compound screening workflows and ensure consistency in high-density plate layouts.
